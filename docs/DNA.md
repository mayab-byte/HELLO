# קובץ ה-DNA

`dna.ts` בשורש הפרויקט הוא הקובץ היחיד שמגדיר מי האתר הזה.
בשכפול לפרויקט לקוח חדש — זה הקובץ שעורכים, ובדרך כלל היחיד.

---

## מה נגזר ממנו

| מה-DNA | לאן זה מגיע |
|---|---|
| `design.colors` · `design.fonts` · `design.shape` · `design.layout` | משתני CSS שמוזרקים ב-`<head>` לפני כל סגנון אחר |
| `design.fonts` | קישור Google Fonts, נבנה אוטומטית |
| `brand` · `seo` | `<title>`, description, Open Graph |
| `identity` | פרטי קשר בפוטר, בסקשן ה-CTA ובכל מקום אחר |
| `accessibility.coordinator` | הצהרת הנגישות |
| `sections` | אילו סקשנים מוצגים בעמוד הבית |
| `nav` · `legalLinks` | התפריט הראשי, תפריט הפוטר, הקישורים המשפטיים |

**מה לא שם:** נוסחי הטקסט של הסקשנים. הם ב-`content/site.ts`,
כי הם משתנים לפי תוכן ולא לפי זהות.

## מבנה

```
meta           לקוח, פרויקט, גרסה, תאריך עדכון
brand          שם, שם קצר, סלוגן, לוגו
identity       ישות משפטית, ח.פ., טלפון, מייל, כתובת, שעות, רשתות
accessibility  רמה, תקן, רכז נגישות, תאריך ההצהרה
design         colors · fonts · shape · layout
seo            כתובת האתר, תבנית כותרת, description, שפה, OG, אנליטיקס
sections       מתג true/false לכל סקשן בעמוד הבית
nav            תפריט — כל פריט מקושר לסקשן שלו
legalLinks     הצהרת נגישות, מדיניות פרטיות, תנאי שימוש
```

## שני מנגנונים שמונעים תקלות שקטות

### 1. בדיקת ניגודיות AA בכל בנייה

```bash
npm run check:dna
```

רץ אוטומטית לפני כל `npm run build` וגם ב-CI. בודק 16 צמדי צבעים
מול הסף של WCAG 2.1 — 4.5:1 לטקסט, 3:1 לרכיבי ממשק. **צבע שנכשל
מפיל את הבנייה** במקום להגיע לאוויר.

זה לא תיאורטי: הבדיקה תפסה שחיווי הפוקוס הכתום על רקע המותג הכהה
נותן 2.06:1 בלבד — בסקשן שבו יושב טופס יצירת הקשר. `axe` לא בודק
ניגודיות של חיווי פוקוס, ולכן זה עבר ביקורת מלאה בלי להתגלות.
מכאן `--focus-on-dark`, המשמש על סקשן ה-CTA והפוטר.

### 2. תפריט מסונן לפי הסקשנים הפעילים

לכל פריט תפריט יש `section`. כיבוי סקשן ב-`sections` מסיר גם את
הקישור אליו — אחרת נשארים בתפריט עוגנים שמובילים לשום מקום.

## שכפול ללקוח חדש

1. **`dna.ts`** — שם, פרטי קשר, צבעים, גופנים, רכז נגישות, אילו סקשנים
2. `npm run check:dna` — לוודא שהפלטה עוברת AA
3. **`content/site.ts`** — נוסחי הטקסט
4. **`public/images/`** — התמונות
5. `?edit` — סגירת פינישים ב-Design Studio
6. `npm run build`

> **התמונות אינן חלק מה-DNA.** ה-placeholders הם SVG בצבעים קבועים,
> והם נועדו להיות מוחלפים בתצלומים אמיתיים של הלקוח — לא להיצבע מחדש.

## דוגמה: החלפת מותג מלאה

נבדק בפועל — עריכה של `dna.ts` בלבד, בלי לגעת בשום קובץ אחר:

| שדה | מ- | אל |
|---|---|---|
| שם | שם העסק | ירוק בעיר |
| צבע מותג | `#1d4ed8` כחול | `#15803d` ירוק |
| גופן כותרות | Heebo | Secular One |
| גופן גוף | Assistant | Rubik |
| רדיוס | `12px` | `2px` |
| גלריה ומאמרים | פעילים | כבויים |

התוצאה: כותרת, גופנים, פלטה, פינות, לוגו, פוטר וסקשנים — הכל השתנה.
הגלריה והמאמרים נעלמו מהעמוד **וגם מהתפריט**.
